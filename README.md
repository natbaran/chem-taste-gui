# 🧪 ChemTaste GUI

Predict the taste of small molecules and visualize their 2D structures using RDKit.

## Features

- Interactive GUI using Streamlit
- Predict taste of molecules from a predefined dictionary
- Visualize 2D molecular structures
- Works for sweet, bitter, salty, sour, minty, spicy, umami tastes

## Molecules included

- Glucose (sweet)
- Fructose (sweet)
- Caffeine (bitter)
- Sodium chloride (salty)
- Citric acid (sour)
- Lactic acid (sour)
- Vanillin (sweet)
- Menthol (minty)
- Gingerol (spicy)
- Capsaicin (spicy)
- Monosodium glutamate (umami)
